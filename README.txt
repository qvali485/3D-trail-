QUANTUM EXPLORER — FOUR-PAGE WEBSITE PROTOTYPE

FILES
- index.html: Page 1 — Welcome / Inspire
- understand.html: Page 2 — Understand the system
- explore.html: Page 3 — Explore the hardware layers
- build.html: Page 4 — Try an interactive one-qubit circuit demonstration
- sources.html: Research and source links for team review
- styles.css and site.js: design and interactions
- assets/: user-supplied Qbit Force / quantum facility images

HOW TO VIEW
1. Extract the ZIP folder.
2. Open index.html in a modern browser (Chrome recommended).
3. Navigate using the four top navigation links.

The pages are static and intended to work offline except for Google Fonts and external source links. The interactive circuit demonstration runs locally in the browser.

IMPORTANT
This is an independent concept prototype for team discussion, not an official Qbit Force website. Images were supplied by the user. Confirm usage rights, facility naming, hardware labels, image provenance, interview permissions and all quotations before public deployment. The circuit demonstration is a simplified ideal simulation and does not run on real quantum hardware.
